# metz-a-pied
Metz à pied : PWA installable qui crée un parcours de visite de Metz selon vos intérêts, votre temps, votre rythme et votre budget. Carte OpenStreetMap, GPS en direct, étapes ordonnées sans allers-retours, pauses gourmandes lorraines, fiches des lieux (histoire, anecdote, conseil photo) et mode hors ligne. HTML/CSS/JS vanilla, sans build.
